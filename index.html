Git Workflow

A simple workflow for developing a website locally with MAMP, tracking changes with Git, and storing the project on GitHub.

1. Your Local Project

Your website lives on your computer, usually inside your MAMP htdocs folder. 

/Applications/MAMP/htdocs/my-project/

my-project/
├── index.php
├── css/
├── js/
├── images/
└── includes/

MAMP runs the website locally so you can test it in your browser. 

http://localhost:8888/my-project/

2. Git

Git keeps track of changes to your project.

Check the current status:

git status

See what you've changed:

git diff

3. Get the Latest Code

Before starting work, update your local copy. 

git checkout main
git pull origin main

4. Create a Branch

Create a separate branch for the feature or change you're working on. 

git checkout -b feature/contact-form

Examples:

feature/login
feature/new-homepage
fix/mobile-menu
fix/contact-form

5. Develop with MAMP

Make your changes to the project and test them using MAMP.

  1. Edit your files.
  2. Run the site through MAMP.
  3. Test the changes in your browser.
  4. Fix any problems.
  5. Repeat until everything works.

6. Stage Your Changes

Once you're happy with your changes: 

git add .

Or add individual files: 

git add index.php
git add css/style.css

7. Commit

Create a snapshot of your changes. 

git commit -m "Add contact form"

Try to make commit messages describe what you changed.

8. Push to GitHub

Send your branch to GitHub. 

git push -u origin feature/contact-form

9. Pull Request

Go to GitHub and create a Pull Request from your feature branch into main.

After the changes are reviewed, the branch can be merged into main.

10. Update Your Local Main Branch

After the Pull Request is merged: 

git checkout main
git pull origin main

Common Commands

Command What it does
git status Shows changed files
git pull Gets changes from GitHub
git checkout -b branch-name Creates a new branch
git add . Stages changes
git commit -m "message" Saves a snapshot
git push Sends changes to GitHub
git diff Shows exactly what changed

Important

Do not commit passwords, API keys, database credentials, or other sensitive information.
